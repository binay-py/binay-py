### ⚙️ How I build

- **No backend unless the problem needs one.** Less to run, less to breach, less to ask people to trust.
- **Your key, not mine.** Where a service costs money per request, you bring your own credentials.
- **Vanilla, mostly.** No framework, no bundler, no build step — it keeps extensions small and old repos openable.
- **Docs that match the code.** A README describing a folder that no longer exists is worse than no README at all.
